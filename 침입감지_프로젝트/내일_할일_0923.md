## 준비물

| 물건 | 개수 | 비고 |
|---|---|---|
| **LED** 초록·노랑·빨강 | 3개 | 또는 RGB LED(다리 4개) 1개 |
| **저항 220~330Ω** | 3개 | 220Ω = 빨강-빨강-갈색-금 / 330Ω = 주황-주황-갈색-금. **필수** |
| **브레드보드** | 1개 | 있으면 훨씬 편하다 |
| **점퍼선 암-수** | 4개 | 보드 핀이 수컷이므로 **암(보드) - 수(브레드보드)** |
| 아기 인형 | 1개 | 이미 있음 |
| 커터칼 | 1개 | 이미 있음 |
| **멀티탭(콘센트)** | 1개 | **outlet 검출률을 아직 한 번도 못 쟀다** |
| **줄자 또는 자** | 1개 | 거리별 측정에 필요. 없으면 바닥에 테이프로 표시 |

> 브레드보드가 없으면 암-암 점퍼로 LED 다리에 직접 꽂아도 되지만 저항을 끼우기 어렵다.
> 저항만 있으면 브레드보드 없이도 어떻게든 되지만, 있는 편이 훨씬 빠르다.

## 2. 검출 거리 2배 만들기 (1시간) — 오늘의 가장 큰 발견에 대한 대응

오늘 확인된 것 : **INT8 은 약 50cm, FP32 도 약 1m 밖에서는 칼을 못 찾는다.**
원인은 입력 해상도다. 320 입력이라 2m 거리의 칼이 **21픽셀**밖에 안 된다.

**입력을 640으로 올리면 42픽셀이 되어 유효 거리가 그대로 2배가 된다.**
그리고 **이미 640으로 학습되어 있으므로 재학습이 필요 없다. 내보내기만 다시 하면 된다.**

### Colab 에서 (5분)

```python
!yolo export model=/content/runs/train640/weights/best.pt format=litert imgsz=640 data={DATA} quantize=8
!yolo export model=/content/runs/train640/weights/best.pt format=litert imgsz=640 data={DATA}
```

나온 파일을 **`by_int8_640.tflite` / `by_best_640.tflite`** 로 이름 붙여 내려받는다.

> 팀원 모델(v2)도 640으로 내보내 주면 더 좋다. 그쪽이 지금 성능이 더 좋으므로.

### 보드에서 (20분)

```bash
python3 bench_models.py by_int8_640.tflite      # 추론 시간 확인 (예상 약 36ms)
python3 detect_rate.py --save                   # 320 판과 640 판을 같은 장면으로 비교
```

**확인할 것** : 640 INT8 의 추론이 50ms 예산 안에 들어오는가, 그리고 검출 거리가 실제로 늘었는가.

## 3. 거리별 검출률 표 (30분) — 보고서의 핵심 표

같은 물체를 **거리만 바꿔** 세 번 잰다. 바닥에 테이프로 위치를 표시해 두면 재현된다.

```bash
python3 detect_rate.py --wait 10 --save     # 0.5 m
mv rate_out/scene.jpg rate_out/scene_05m.jpg
mv detect_rate.csv detect_rate_05m.csv

python3 detect_rate.py --wait 10 --save     # 1.0 m
mv rate_out/scene.jpg rate_out/scene_10m.jpg
mv detect_rate.csv detect_rate_10m.csv

python3 detect_rate.py --wait 10 --save     # 2.0 m
mv rate_out/scene.jpg rate_out/scene_20m.jpg
mv detect_rate.csv detect_rate_20m.csv
```

**칼·인형·멀티탭을 모두 한 화면에** 넣고 찍을 것. outlet 은 아직 한 번도 못 쟀다.

나오는 결론 : **"이 시스템의 유효 감시 거리는 N m"**, 그리고
**"INT8 은 몇 m 까지 쓸 수 있는가"**.

## 4. 카메라 20 FPS 원인 확정 (20분)


> 그래도 몇 fps 까지 나오는지는 알아야 입력 크기를 정할 근거가 된다.
