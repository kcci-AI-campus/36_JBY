# Team10 — 저전력 온디바이스 AI 기반 위험구역 침입 감지 시스템

> 영유아가 콘센트·칼 등 위험물에 접근하면 실시간으로 경보하는 엣지 AI 시스템.
> 라즈베리파이 5 단독으로 동작하며, 추가 센서 없이 **카메라만으로** 연산을 제어해 전력을 아낀다.

- **과정** : AI 시스템반도체 설계 2기 (서울기술교육센터)
- **기간** : 2026-09-21 ~ 2026-09-28
- **하드웨어** : Raspberry Pi 5 + USB 웹캠 (NPU 없음, CPU 추론)

---

## 1. 무엇을 만드는가

```
평상시          움직임 없음        → AI 정지          CPU 최소
움직임 감지     프레임 차분 트리거  → AI 기동
대상 확인       YOLO11n 검출       → baby / adult / knife / outlet
위험 판정       아기가 위험물 근접  → LED 빨강 + 음성 경고
```

핵심은 **"AI를 언제 얼마나 돌릴 것인가"** 이다.
상시 추론 대신 필요할 때만 깨우고, 상황에 따라 모델·스레드·추론 주기를 단계적으로 조절한다.

---

## 2. 검출 클래스

| # | 클래스 | 역할 |
|---|---|---|
| 0 | `baby` | **감지 주체** — 위험물에 접근하면 경보 |
| 1 | `adult` | 성인 — 경보하지 않음 (오경보 방지) |
| 2 | `knife` | 위험물 |
| 3 | `outlet` | 위험물 (콘센트·멀티탭) |

---

## 3. 판정 로직

```
위험 반경 = 위험물 박스 폭 × 1.5
baby 박스가 위험 반경 안에 들어오고 0.5초 유지  →  경보
adult 만 있으면 경보하지 않음
```

반경을 고정 픽셀이 아니라 **위험물 박스 폭의 배수**로 잡아 원근을 자동 보정한다.
(멀리 있으면 박스도 작아지므로 기준이 함께 줄어든다)

**한계** — 단안 카메라는 깊이를 모르므로 화면상 거리로 판정한다.
대상이 같은 평면(책상 위)에 놓이는 시연 조건에서는 유효하나,
깊이 차가 큰 환경에서는 스테레오 카메라나 거리 센서가 필요하다.

## 7. 실행 방법

### 학습 (Colab)

1. `학습_Colab.ipynb` 업로드, 런타임을 **T4 GPU**로 변경
2. `merged.zip` 업로드 후 순서대로 실행
3. `result.zip` 다운로드 (모델 3종 + 그래프 + 수치)

### 보드 추론

```bash
# 모델과 코드를 보드로
scp best_int8.tflite detect_baby.py willtek@<보드IP>:/home/willtek/work/baby/

# 보드에서
source ~/work/env/bin/activate
cd ~/work/baby
python3 detect_baby.py best_int8.tflite
```

카메라 창이 떠야 하므로 X11이 되는 터미널(MobaXterm 등)에서 실행한다.

조정 가능한 값은 `detect_baby.py` 상단에 모아 두었다.

```python
DANGER_SCALE = 1.5    # 위험 반경 = 위험물 박스 폭 × 이 값
DWELL_SEC    = 0.5    # 이 시간 이상 유지되어야 경보
CONF_TH      = 0.40   # 검출 임계값
```

## 10. 데이터 취급

- 촬영 원본과 학습 데이터는 팀 구글 드라이브에서 관리하며 **저장소에 포함하지 않는다.**
- 사진에 팀원의 얼굴과 신체가 포함되어 있어 공개 저장소에 올리지 않는다.
- 영유아는 실제 촬영이 불가능하여 **유아 인형을 대체물로 사용**했다.
  실제 영유아는 인형과 크기·자세·움직임이 다르므로, 현장 적용 전 재학습이 필요하다.
