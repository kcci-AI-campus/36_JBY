# 저전력 온디바이스 AI 기반 위험구역 침입 감지 시스템

라즈베리파이 5 한 대에서 **카메라 → AI 추론 → 위험 판정 → 알림**까지 모두 처리한다.
서버가 없고, 평상시 영상이 밖으로 나가지 않는다.

> **아기(baby)가 위험물(knife / outlet)의 위험 반경 안에 0.5초 이상 머물면 경보**

- 클래스 : `0 baby`, `1 adult`, `2 knife`, `3 outlet`
- 모델 : YOLO11n → LiteRT(tflite)
- 보드 : Raspberry Pi 5 + USB 웹캠

---

## 1. 무엇이 다른가 — 관계를 판정한다

시중 홈캠이 답하는 질문은 **"무엇이 있는가"** 다.
이 시스템이 답하는 질문은 **"무엇과 무엇의 관계가 위험한가"** 다.

| | 일반 홈캠 | AI 홈캠 | **이 프로젝트** |
|---|---|---|---|
| 1단계 | 모션 감지 | 모션 감지 | 모션 감지(게이팅) |
| 2단계 | — | AI 사람 판별 | AI 4클래스 검출 |
| 3단계 | — | — | **관계·체류 판정** |
| 알림 | "움직임 감지" | "사람이 있습니다" | "**아기가 칼 반경 안에 0.5초 이상**" |

아기만 있으면 알림이 안 간다. 칼만 있어도 안 간다.
**둘이 가까워지고, 그 상태가 유지돼야** 간다.

## 2. 주요 기능

| 기능 | 파일 | 설명 |
|---|---|---|
| 감시 본체 | `detect_baby.py` | 추론·판정·경보. 모든 옵션의 중심 |
| 실시간 웹 화면 | `web.py` | 브라우저·휴대폰에서 보기 (MJPEG) |
| 휴대폰 알림 | `notify.py` | ntfy / telegram. 경보 사진 첨부 |
| 경보 영상 | `clip.py` | 경보 전 3초 + 후 2초 클립 전송 |
| 3색 LED | `led_test.py` | 초록(정상) / 파랑(아기 감지) / 빨강(경보) |

| 집 밖에서 보기 | Cloudflare Tunnel | `--web-url auto` 로 주소 자동 인식 |

## 3. 빠르게 돌려 보기

```bash
# 준비
pip install ultralytics ai-edge-litert flask requests psutil gpiozero lgpio

# 기본
python3 detect_baby.py <모델>.tflite --web

# 실제 제품 구성 (화면 없이, 저전력, 휴대폰 알림, 집 밖 접속)
python3 detect_baby.py <모델>.tflite --no-gui --gate --web --notify --web-url auto --web-token <암호>
```

집 밖에서 보려면 다른 터미널에서 터널을 열어 둔다.

```bash
cloudflared tunnel --url http://localhost:5000
```

전체 옵션과 설명은 **`사용법.md`** 에 있다.

## 4. 측정 결과 (실사용 기준)

> 모든 수치는 `detect_baby.py` 를 실제로 돌려서 얻었다.
> 벤치마크(`bench_models.py`) 수치는 카메라가 없어 실제보다 빠르므로 쓰지 않는다.

### 검출 거리 — 입력 해상도가 결정적이었다

같은 가중치를 입력 크기만 바꿔 내보내 비교했다(다른 변수 없음).

| 입력 | knife 검출률 (1.5~2 m) |
|---|---|
| 320 | **0 %** |
| **640** | **100 %** |

2 m 거리의 15 cm 커터칼은 320 입력에서 **21픽셀**이다. 그 크기에서는 찾을 정보가 없다.

### 속도 — INT8 이 640 을 실시간으로 만든다

| 같은 640 입력 | FPS | CPU | 파일 |
|---|---|---|---|
| FP32 | 7.5 | 89 % | 10.14 MB |
| **INT8** | **21.1** | **72 %** | **2.90 MB** |

### 전력 — 게이팅으로 소비 전력을 62% 줄였다

PMIC(`vcgencmd pmic_read_adc`)에서 직접 측정.

| 조건 | 전력 | **AI 가 쓴 몫** | CPU | 온도 |
|---|---|---|---|---|
| 대기(프로그램 끔) | 1.50 W | — (기준) | — | — |
| 게이팅 끔 | 6.03 W | 4.53 W | 91 % | 57.9 ℃ |
| 게이팅 켬(활동 중) | 3.81~4.54 W | 2.31~3.04 W | 42~59 % | — |
| **게이팅 켬(조용함)** | **2.26~2.61 W** | **0.76~1.11 W** | **7~16 %** | **45.8 ℃** |

**총 전력 6.03 W → 2.26 W (62% 감소).**
대기 전력(1.50 W)을 빼고 AI 가 쓴 몫만 보면 4.53 W → 0.76 W 다.

> **정정 (2026-09-29)** — 아래·위의 "상용 AI 홈캠 2~2.7 W"는 원문과 맞지 않는다. Tapo C210 공식 데이터시트(하드웨어 2.20/2.26/2.28)는 **평소 1.78 W, 최대 3.27 W**(어댑터 9 V 0.6 A)이고 "300 mA ≈ 2.7 W"의 출처는 찾지 못했다. Google Nest Cam 공식 사양에는 **어댑터 7.5 W 만** 있고 평균 소비전력은 없다("약 2 W" 근거 없음). 따라서 "상용 홈캠 수준 유지"도 쓰지 않는다. 쓸 수 있는 말: "공개된 예로 Tapo C210 사양서가 평소 1.78 W 라서, 웹캠이 빠진 우리 값이 더 낮다고 말할 수 없다." 출처: https://static.tp-link.com/upload/product-overview/2024/202403/20240319/Tapo%20C210%202.20&2.26&2.28_Datasheet.pdf · https://support.google.com/googlenest/answer/9250901

> **주의 — 전력은 경쟁 우위가 아니다.**
> 상용 AI 홈캠도 2~2.7 W 로 비슷하다. 여기서 말하는 저전력은
> **"보드의 제한된 전력 예산 안에서 AI 가 돌아가게 만들었다"** 는 뜻이며,
> 위 수치는 **같은 보드·같은 측정 방법으로 잰 내부 Before/After** 다.
>
> 측정 한계 : PMIC 는 메인 5V 레일의 **전류**를 못 잰다(전압만 안다).
> USB 웹캠이 그 레일을 쓰므로 카메라 몫이 빠졌을 수 있다.
> 절대값 비교가 아니라 **조건 간 차이 비교**로만 쓸 것.

### 카메라 — 프레임의 1/3을 버리고 있었다

`CAP_PROP_BUFFERSIZE` 가 1 이면 한 장을 처리하는 동안 도착한 다음 프레임이 버려진다.
3 으로 바꿔 **20 → 30 FPS**. 속도 문제가 아니라 **감시 공백** 문제였다.

## 5. 저전력을 어떻게 구현했나

원래 기획은 **초음파 센서로 무언가 가까이 왔을 때만 추론**하는 것이었다.
센서를 쓸 수 없게 되어 **같은 원리를 화면 변화로 구현**했다.

| | 초음파(원래 계획) | **프레임 차분(구현)** |
|---|---|---|
| 감지 방법 | 초음파 반사 거리 | 직전 프레임과의 픽셀 차이 |
| 비용 | 센서 + 배선 | **약 1 ms** |
| 추론 비용 | 81 ms | 81 ms |

**감시 공백을 만들지 않기 위한 안전장치 세 가지**

1. **위험 상태면 절대 건너뛰지 않는다**
2. **연속 15장을 건너뛰면 강제로 한 번 추론**한다
3. **건너뛴 프레임은 직전 검출 결과를 재사용**한다

2단계로, 조용할 때는 루프 자체를 8 FPS 로 낮춰 **쉰다**(`--gate-idle-fps`).
이것이 전력을 3.04 W → 2.5 W 로 더 내렸고, **판정 재현성까지 개선**했다
(그 전에는 게이팅↔FPS↔차분값의 되먹임으로 같은 장면에서 88.5% / 36.6% 로 흔들렸다).

## 6. 보안·개인정보

| 지점 | 무엇이 나가나 | 현재 | 상용화하려면 |
|---|---|---|---|
| **추론** | **아무것도 안 나간다** | 보드에서 끝 | 그대로 |
| 외부 접속 | 실시간 영상 | 토큰(공유 비밀) | Cloudflare Access / VPN |
| 휴대폰 알림 | 경보 순간 사진 | 공개 ntfy.sh, 3시간 보관 | ntfy 자체 호스팅 |

- **`notify.json` 은 커밋하지 않는다.** `notify.json.example` 을 복사해 쓴다
- **ntfy 토픽 이름은 비밀번호와 같다.** 아는 사람은 누구나 구독·발행할 수 있다
- **터널 주소도 마찬가지다.** 발표 캡처에서 주소창을 가릴 것
- `--web-token` 은 로그인이 아니라 공유 비밀이다. 전체 링크가 새면 막지 못한다

## 7. 아직 측정하지 못한 것 (정직하게)

- **오검출률** — 책을 `knife 46%`, 셔츠를 `outlet 45%` 로 잡는 것을 관찰했으나 수치화하지 못했다
- 기울어진 칼(45°·수직·거꾸로) 검출률
- `outlet` 은 촬영·측정을 하지 못했다
- 야간(적외선) 미지원
- 거리별 검출률 표 → "유효 감시 거리" 미확정
