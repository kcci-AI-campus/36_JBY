# 모델별 검출 점수 비교 — 교육장 보드, 실제 카메라 (2026-09-28 오전, 클로드코드 실행)

조건: 교육장 라즈베리파이 5 (10.10.15.61), LiteRT 2.1.0, 로지텍 C270 640×480. 같은 순간 찍은 사진 10장을 모델마다 똑같이 넣고, 클래스별 최고 점수(신뢰도)의 10장 평균을 비교. 전처리 = letterbox 320 + /255 + NCHW (팀원A님 power_bench.py 와 같음). 스크립트 `cmp5.py`.

## 사람이 인형을 들고 있는 장면 (사진: 모델비교_인형_1150.jpg)

| 모델 | baby | adult | knife | outlet |
|---|---:|---:|---:|---:|
| YOLO11n FP32 | **0.89** | 0.03 | 0.01 | 0.00 |
| YOLO11n INT8 | 0.50 | 0.03 | 0.03 | 0.03 |
| YOLO26n INT8 | **0.02** | 0.00 | 0.01 | 0.00 |
| YOLOv8n INT8 | 0.50 | 0.00 | 0.12 | 0.00 |
| YOLOv10n INT8 | 0.21 | 0.03 | 0.01 | 0.00 |

## 사람만 있는 장면 (사진: 모델비교_사람_1140.jpg, 1장)

| 모델 | 가장 높은 점수 |
|---|---|
| YOLO11n FP32 | adult 0.90 |
| YOLO11n INT8 | adult 0.37 |
| YOLO26n INT8 | knife 0.03 (사실상 검출 없음) |

## 읽는 법
- INT8 은 전부 FP32 보다 점수가 크게 낮다: 같은 인형을 FP32 0.89, YOLO11n·YOLOv8n INT8 0.50, YOLOv10n INT8 0.21. 문턱값 0.40 이면 YOLOv10n INT8 은 인형을 못 잡는다.
- YOLO26n INT8 은 인형도 사람도 0.03 이하 = 이 파일은 보드에서 사실상 동작하지 않는다. 팀원A님 Colab 평가표에는 mAP50-95 0.693 이므로 Colab 평가 방식과의 차이 또는 INT8 변환 문제로 보이나 **원인 미확인**.
- 신뢰도 차이는 주말 집 보드 비교(YOLO11n INT8 이 FP32 보다 0.2~0.3 낮음)보다 크다(0.39 낮음). 장면·조명이 달라서일 수 있으나 미확인.
- 한 장면·10장 결과라 모델 순위를 확정할 근거로는 부족하다. 검출률 결론은 실험표 6-3·6-4(칼 1.5 m·2 m, 60장) 로.

## 칼 장면 (사진: 칼비교_원본_1200.jpg, 박스: 칼비교_박스위치_1200.jpg)

카메라가 책상을 위에서 내려다보는 각도, 칼은 화면 맨 위 끝에 일부만 걸침, 가운데 노트북 키보드(비닐 덮개).

| 모델 | knife (10장 평균) | 가장 높은 knife 박스가 어디였나 (1장) |
|---|---:|---|
| YOLO11n FP32 320 | 0.47 | **키보드 아랫줄 (0.62) → 오검출** |
| YOLO11n INT8 320 | 0.03 | – |
| YOLO26n INT8 | 0.02 | – |
| YOLOv8n INT8 | 0.50 | 진짜 칼 (0.50) |
| YOLOv10n INT8 | 0.00 | – |
| YOLO11n FP32 640 | 0.49 | 진짜 칼 (0.39) |
| YOLO11n INT8 640 (옛 가중치) | 0.44 | 미확인 |

- 10장 평균 점수만 보면 오검출과 진짜 검출이 섞여 구분되지 않는다 → 박스 위치까지 봐야 한다.
- 320 FP32 는 일부만 보이는 칼보다 흰 키보드 줄을 더 칼답다고 봤다. 640 은 진짜 칼을 잡았다(칼이 작게 보일 때 입력 해상도가 중요하다는 9/23 TS-22 와 같은 방향).
- 칼이 화면 끝에 잘려 있어 공정한 비교가 아니다. 칼 전체가 보이게 다시 재야 한다.

## 칼 장면 2 — 사람이 커터칼을 세워 들고 있음 (사진: 칼비교2_손에들고_박스위치.jpg)

| 모델 | knife 10장 평균 | 마지막 1장의 가장 높은 knife 박스 | adult 10장 평균 |
|---|---:|---|---:|
| YOLO11n FP32 320 | 0.42 | 0.00, 화면 오른쪽 아래 의자 (칼 아님) | 0.89 |
| YOLO11n INT8 320 | 0.22 | 0.01, 오른쪽 아래 (칼 아님) | 0.50 |
| YOLO26n INT8 | 0.01 | 0.00 | 0.00 |
| YOLOv8n INT8 | 0.26 | 0.14, 책 더미 (칼 아님) | 0.50 |
| YOLOv10n INT8 | 0.00 | 0.00 | 0.27 |
| **YOLO11n FP32 640** | **0.61** | **0.46, 진짜 칼** | 0.09 |
| YOLO11n INT8 640 (옛 가중치) | 0.10 | 0.02, 진짜 칼 자리 | 0.03 |

- 손에 든 칼을 제대로 잡은 것은 640 FP32 하나. 320 모델들은 10장 중 일부 장에서만 점수가 났고, 마지막 장에서는 칼이 아닌 곳에 가장 높은 박스를 뒀다.
- 640 FP32 는 칼을 잘 잡는 대신 사람(adult)을 거의 못 잡았다(0.09). 이유 미확인.
- 한 장면·10장 결과라 확정 근거로는 부족. 거리별 검출률은 실험표 6-3·6-4 로.

## 칼 장면 3 — 같은 칼(학습 때 쓴 파란 커터칼)을 다시 세워 들고 있음 (사진: 칼비교3_파란칼_세워서.jpg)

**정정**: 장면 2·3 모두 학습에 쓴 같은 파란 커터칼이다(정보윤 확인). 클로드코드가 사진 색만 보고 "다른 칼일 수 있다"고 한 것은 틀린 추측이었다.

| 모델 | knife 10장 평균 (장면 2 → 장면 3) | 장면 3 마지막 사진의 knife 박스 |
|---|---|---|
| YOLO11n FP32 320 | 0.42 → 0.01 | 칼 아님 |
| YOLO11n INT8 320 | 0.22 → 0.01 | 책 (칼 아님) |
| YOLO26n INT8 | 0.01 → 0.18 | 칼 아님 |
| YOLOv8n INT8 | 0.26 → 0.23 | 책 0.30 (칼 아님) |
| YOLOv10n INT8 | 0.00 → 0.01 | 칼 아님 |
| YOLO11n FP32 640 | 0.61 → 0.32 | 책 0.21 (칼 아님) |
| YOLO11n INT8 640 (옛 가중치) | 0.10 → 0.15 | 칼 0.14 |

- **같은 칼인데 드는 자세만 바뀌어도 점수가 크게 흔들린다** (640 FP32 0.61 → 0.32, 320 FP32 0.42 → 0.01). 커터칼을 세워 들면 화면에 보이는 폭이 좁아져 모델이 칼로 확신하지 못하는 것으로 보인다(가설, 자세별로 재서 확인 필요).
- 학습 데이터 사실(칼 사진 405장 중 합성 150장·37 %, 배경만 있는 사진 0장, 칼 박스 방향은 가로 132·세로 146·비슷 127로 고름)은 그대로 유효. "칼 종류가 적어서" 는 이번 결과와 관계없음.

## 오검출 60장 — 칼·인형 없는 장면 (사진: 오검출_60장_장면.jpg, 스크립트 fp_test.py)

장면: 사람 한 명, 뒤쪽 책상 위 책·가방, 의자. 칼·콘센트·인형 없음 → knife·outlet·baby 로 잡히면 전부 오검출. 같은 60장을 모델마다 넣고 "그 클래스 최고 점수가 문턱 이상인 프레임 수".

| 모델 | knife ≥0.25 | knife ≥0.40 | knife ≥0.50 | outlet ≥0.40 | baby ≥0.40 | knife 최고점 |
|---|---:|---:|---:|---:|---:|---:|
| YOLO11n FP32 320 | 0 | 0 | 0 | 0 | 0 | 0.00 |
| YOLO11n INT8 320 | 0 | 0 | 0 | 0 | 0 | 0.02 |
| YOLOv8n INT8 320 | 0 | 0 | 0 | 0 | 0 | 0.21 |
| YOLO11n FP32 640 | **8** | **1** | **1** | 0 | 0 | **0.50** |

- 이 장면에서는 640 이 320 보다 knife 오검출이 **많았다** (60장 중 1장이 0.50). 320 은 0.
- 앞선 키보드 장면에서는 320 이 키보드를 0.62 로 칼이라 했다 → **오검출은 모델보다 장면(무엇이 화면에 있나)에 따라 달라진다.** "640 이면 오검출이 준다" 는 이 데이터로는 말할 수 없다.
- 640 의 0.50 오검출이 화면 어디였는지는 기록하지 못했다(마지막 장만 박스를 그렸는데 그 장은 0.25 미만).
