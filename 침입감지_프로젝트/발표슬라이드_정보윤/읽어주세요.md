## 다시 만드는 법 (숫자 고친 뒤)
1. `생성스크립트/build_ppt.py` 안의 표·문구·대본(SCRIPTS)을 고친다. 그림 숫자는 `make_slide_figs.py`.
2. 실행 (시스템 파이썬 3.10에 python-pptx·matplotlib·Pillow 설치돼 있음):
   ```
   python 생성스크립트/make_slide_figs.py
   python 생성스크립트/build_ppt.py
   python 생성스크립트/preview_ppt.py 발표_정보윤파트_0927_v6.pptx 미리보기
   ```
3. 팀장 파일에 합칠 때: PowerPoint 에서 팀장 파일을 열고 "슬라이드 재사용" 으로 이 파일의 4장을 가져오면 서식(마스터)이 같아 그대로 붙는다. 노트도 같이 온다.
