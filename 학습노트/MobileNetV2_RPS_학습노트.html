1. 이 실습이 뭐야

한 줄로 뭘 만드는 거야?
손 사진을 넣으면 가위(0) / 바위(1) / 보(2) 중 하나를 답하는 분류 모델을 Colab에서 만들고, 그걸 라즈베리파이에서 돌아가는 파일(.tflite)로 변환하는 것이다. 지난주 크랙 실습이 "모델 만들기"에서 끝났다면, 이번엔 "만든 모델을 작은 기기로 보내기"까지 간다. 그래서 과목 이름이 On-Device AI다.
지난주 크랙 실습이랑 뭐가 달라?
지난주 (LAB_09 크랙)이번 (EX_03 가위바위보)
클래스2개 (없음/있음)3개 (가위/바위/보)
사진 크기64×64224×224
모델Conv 3층을 처음부터 학습구글이 미리 학습해 둔 MobileNetV2를 빌려와 끝부분만 학습 (전이학습)
정규화/255를 직접모델 안에 넣어서 자동
저장안 함가장 좋은 epoch를 자동 저장(콜백) → Drive 백업 → tflite 변환
결과val 98~99%val 100% (30 epoch, 2분)
코드 골격(읽기 → 나누기 → 모델 → compile → fit → 그래프)은 완전히 같다. 새로 배우는 건 9번(모델 생성), 12번(콜백), 16~17번(저장과 변환)이다.
전이학습(Transfer Learning)이 뭐야?
남이 큰 데이터로 미리 학습해 둔 모델을 가져와서, 내 문제에 맞게 끝부분만 조금 더 학습시키는 방법이다. MobileNetV2는 구글이 ImageNet(사진 140만 장, 1,000종류)으로 학습한 모델이라 "선, 모서리, 질감, 손 모양" 같은 특징을 이미 뽑을 줄 안다. 우리는 그 능력을 그대로 쓰고, 마지막에 "가위/바위/보 셋 중 뭐냐"를 판단하는 작은 층만 새로 붙여 학습한다.
외국어를 이미 잘하는 사람을 채용해서 우리 회사 용어만 가르치는 것. 처음부터 언어를 가르치는 것(지난주 방식)보다 훨씬 빨리, 적은 자료로 잘하게 된다. 그래서 2,172장으로 2 epoch 만에 94%가 나온다.

2. 단어 사전 (먼저 읽기)

지난주 노트에 있던 단어(CNN, Conv2D, ReLU, Dropout, softmax, epoch, loss, accuracy, 과적합 등)는 뺐다. 이번에 새로 나오는 것만.
단어한 줄 뜻비유
MobileNetV2구글이 2018년에 만든, 스마트폰용으로 가볍게 설계된 CNN. 층은 150개가 넘지만 파라미터는 226만 개로 작다경차. 작지만 잘 달린다
ImageNet사진 140만 장, 1,000종류(개, 고양이, 자동차…)짜리 대형 데이터셋. 여기서 학습한 가중치를 weights="imagenet"으로 받는다세상 사진 백과사전
전이학습미리 학습된 모델을 가져와 끝부분만 새로 학습경력직 채용
base_model, 동결(freeze)빌려온 본체를 base_model이라 부르고, trainable=False로 가중치를 고정하는 걸 동결이라 한다본체는 잠그고 뚜껑만 교체
include_top=False원래 모델의 마지막 층(1,000종류 분류기)을 떼고 가져온다는 뜻. 우리는 3종류라 우리 것을 붙인다남의 명함은 떼고 내 명함 붙이기
preprocess_inputMobileNetV2가 기대하는 입력 범위(-1~1)로 픽셀값을 바꿔 주는 함수. 이걸 모델 안에 넣어서 /255를 안 한다모델 전용 어댑터
GlobalAveragePooling2D7×7×1280 특징 지도를 채널마다 평균 내서 1280개 숫자 한 줄로 만든다. Flatten보다 파라미터가 훨씬 적다7×7 표를 평균 한 칸으로 요약
Functional APIx = 층(x) 식으로 층을 함수처럼 이어 붙이는 Keras 문법. 지난주 model.add()(Sequential)와 결과는 같다블록을 손으로 하나씩 연결
learning_rate한 번에 가중치를 얼마나 크게 고칠지. 1e-4 = 0.0001. 빌려온 모델을 망치지 않게 작게 잡는다다이얼 돌리는 폭
콜백 (callback)학습 도중 매 epoch 끝에 자동으로 실행되는 작업. 여기선 "가장 좋은 모델 저장"매 바퀴 끝나면 자동 세이브
ModelCheckpoint, save_best_only모델을 파일로 저장하는 콜백. save_best_only=True면 val_loss가 이전 최고보다 좋아졌을 때만 덮어쓴다최고 기록 갱신 때만 저장
.keras 파일Keras 모델을 통째로(구조 + 가중치) 저장한 파일. PC/Colab에서 다시 불러올 수 있다완제품 상자
LiteRT, .tflite구글의 경량 실행기. 옛 이름이 TensorFlow Lite. 스마트폰·라즈베리파이에서 모델을 돌리기 위한 형식이 .tflite. 학습은 못 하고 실행만 한다휴대용 재생기 전용 파일
TFLiteConverterKeras 모델을 .tflite로 바꿔 주는 도구포맷 변환기
BatchNormalizationsummary에 잔뜩 나오는 층. 층 사이 값의 범위를 일정하게 맞춰 학습을 안정시킨다. MobileNetV2 안에 들어 있고 우리가 만지진 않는다구간마다 볼륨 자동 조절
DepthwiseConv2DMobileNetV2가 가벼운 비결. 채널마다 따로 필터를 돌려 계산량을 크게 줄인 합성곱부서별로 따로 처리

7. 폴더별 사진 읽기

IMG_SIZE = 224
사진을 224×224로 줄인다. 지난주는 64였는데 왜 224인가? MobileNetV2가 ImageNet에서 224×224로 학습됐기 때문이다. 빌려온 모델이 익숙한 크기로 맞춰 주는 것. 다른 크기(96, 128, 160, 192)도 되지만 224가 기본이다.
%%time
first = True
for ind in range(0, 3, 1) :
    path = files_path + '/' + str(ind) + '/*.*'
    print(path)
    files = glob.glob(path)
    tmpx = np.array([(cv2.resize(cv2.cvtColor(cv2.imread(x, cv2.IMREAD_COLOR), cv2.COLOR_BGR2RGB), (IMG_SIZE,IMG_SIZE))) for x in files])
    tmpy = np.array([ind] * len(files))

    xtrain, xtest, ytrain, ytest = train_test_split(tmpx, tmpy, test_size=0.2, random_state=123)

    if first == True:
        train_data = xtrain.copy()
        train_labels = ytrain.copy()
        test_data = xtest.copy()
        test_labels = ytest.copy()
        first = False
    else :
        train_data = np.concatenate((train_data, xtrain))
        train_labels = np.concatenate((train_labels, ytrain))
        test_data = np.concatenate((test_data, xtest))
        test_labels = np.concatenate((test_labels, ytest))
줄뜻
%%time셀 실행 시간 측정. 강사 결과 약 8초.
first = True첫 폴더인지 표시하는 깃발.
for ind in range(0, 3, 1) :지난주와 유일하게 다른 줄. ind = 0, 1, 2. 폴더 3개 = 클래스 3개. 0=scissors(가위), 1=rock(바위), 2=paper(보). 이 번호는 보드 코드의 ansToText와 똑같아야 한다.
path = files_path + '/' + str(ind) + '/*.*'/content/RPS_Dataset/0/*.*. 그 폴더의 모든 파일.
print(path)어느 폴더를 읽는지 표시. 출력에 3줄 찍힌다.
files = glob.glob(path)파일 경로 약 900개짜리 리스트.
tmpx = np.array([…for x in files])안쪽부터: imread(BGR로 읽기) → cvtColor(RGB로) → resize(224×224). 파일마다 반복해 (약900, 224, 224, 3) 배열.
tmpy = np.array([ind] * len(files))정답. 폴더 번호를 사진 수만큼 복제. 폴더 이름이 곧 라벨.
train_test_split(…, test_size=0.2, random_state=123)폴더마다 8:2로 나눔. 903장이면 722 / 181. 섞는 방식 고정.
if first == True: … copy()첫 폴더(가위)면 최종 변수 4개에 복사.
else: np.concatenate(…)바위, 보는 뒤에 이어 붙임. 최종 학습 2,172장, 시험 545장.
왜 2,172 / 545야?
폴더별 사진이 903, 907, 907장 = 2,717장. 각각 8:2로 나누면 학습 722+725+725 = 2,172, 시험 181+182+182 = 545. 시험 배열은 앞 181장이 가위, 다음 182장이 바위, 마지막 182장이 보로 정렬된 채 들어 있다. 11번 그림에서 윗줄이 가위·바위, 아랫줄이 바위·보로 나오는 이유.

정규화를 모델 안에 넣으면 좋은 점이 하나 더 있다. 나중에 보드에서 tflite로 돌릴 때도 카메라 사진(0~255)을 그대로 넣으면 된다. 보드 코드 EX_04에 "Normalization 처리 안함 (모델 내에서 -1 ~ 1로 변환 처리함)"이라고 같은 주석이 있는 게 그 이유다.

줄뜻
inputs = tf.keras.Input(shape=(224, 224, 3))입력 사진 한 장의 모양 선언. 지난주는 model.add(Input(...))였는데, 이번엔 변수 inputs에 담아 다음 줄로 넘긴다. 이 "변수에 담아 넘기기"가 Functional API 문법이다.
x = …mobilenet_v2.preprocess_input(inputs)픽셀 0~255를 -1~1로 바꾸는 층을 모델 안에 넣는다. 계산은 x/127.5 - 1. summary에 true_divide, subtract로 보이는 게 이것.
base_model = tf.keras.applications.MobileNetV2(Keras에 내장된 MobileNetV2를 만든다. 괄호 안 옵션 3개가 전이학습의 핵심.
weights="imagenet",ImageNet으로 학습된 가중치를 인터넷에서 받아 채운다(약 9MB, 처음 한 번). None이면 빈 모델.
include_top=False,원래 달려 있던 "1,000종류 분류" 마지막 층을 뗀다. 우리는 3종류라 우리 층을 붙일 것.
input_tensor = x입력을 방금 만든 x(전처리 거친 것)로 연결. 이 줄 덕에 전처리 → MobileNetV2가 한 모델로 이어진다.
base_model.trainable = False동결. MobileNetV2 안의 226만 개 가중치를 학습 때 고치지 않는다. 빌려온 실력을 그대로 쓰고, 적은 데이터로 망가뜨리지 않기 위해서. summary의 Non-trainable params 2,257,984가 이것.
x = base_model.outputMobileNetV2의 마지막 출력. 모양 (7, 7, 1280). 224×224 사진이 7×7 격자 × 특징 1,280종류로 압축된 것.
x = GlobalAveragePooling2D()(x)7×7 격자를 채널마다 평균 내서 1,280개 한 줄로. 지난주 Flatten(8×8×64 = 4,096) 자리에 해당하지만, 평균을 내니 위치 정보에 덜 민감하고 파라미터도 안 늘어난다.
x = Dense(128, activation='relu')(x)새로 붙인 층 1. 1,280 → 128. 파라미터 1,280×128 + 128 = 163,968개.
x = Dropout(0.2)(x)학습 때 20%를 꺼서 과적합 방지. 지난주는 0.4였는데, 새로 배우는 층이 작아서 약하게.
outputs = Dense(3, activation='softmax')(x)새로 붙인 층 2. 128 → 3. 가위/바위/보 확률. 파라미터 128×3 + 3 = 387개.
model = tf.keras.Model(inputs, outputs)"입력은 inputs, 출력은 outputs"라고 지정해 하나의 모델로 묶는다. Sequential에서는 add 순서가 곧 연결이었지만, Functional은 이렇게 양 끝을 알려줘야 한다.
model.summary()150줄 넘는 표가 나온다. 맨 끝 3줄만 보면 된다.

줄값뜻

summary에 나오는 Conv1, bn_Conv1, expanded_conv_depthwise, block_1_expand… 이건 다 뭐야?
MobileNetV2 내부 층 이름들이다. 우리가 만든 게 아니라 빌려온 것이고, 동결돼 있어서 건드리지 않는다. 패턴만 알면 된다. block_N_expand(채널 늘리기, Conv2D) → block_N_depthwise(채널별 따로 합성곱, 가벼움) → block_N_project(채널 줄이기). 이 3단 묶음이 16번 반복되고 사이사이에 BatchNormalization과 ReLU가 끼어 있다. 가로세로는 224 → 112 → 56 → 28 → 14 → 7로 줄고 채널은 3 → 32 → … → 1280으로 는다. 지난주 Conv → Pool 3묶음의 "큰 버전"이라고 보면 된다.

21. 복습 체크리스트

  • 전이학습이 뭔지, 왜 2,172장으로 2 epoch 만에 94%가 나오는지 말할 수 있다
  • weights="imagenet", include_top=False, trainable=False 세 옵션이 각각 뭘 하는지
  • Trainable 164,355가 어디서 나오는지 (1,280×128+128 + 128×3+3)
  • 왜 /255를 안 하는지, 그게 보드 코드와 어떻게 연결되는지
  • 콜백 save_best_only=True가 뭘 저장하는지, 15번에서 왜 다시 불러오는지
  • .keras와 .tflite의 차이, 어느 파일이 보드로 가는지

  • 교육장에서 분류 모델 인식률이 낮았던 이유와, 커리큘럼이 그걸 어떻게 풀어 가는지
