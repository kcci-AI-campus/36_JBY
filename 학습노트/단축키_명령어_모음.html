    실전 예: 모듈 포트 목록 → 테스트벤치 연결로 바꾸기

    설계 파일의 포트 목록을 복사해 와서 input/output 을 지우고, 앞에 . 과 뒤에 (이름) 을 붙이는 작업. 11줄을 한 줄씩 고치지 않는다.

    전 (gates.v 에서 복사)
        input  a,
    input  b,
    output y0,
    output y1,
    ...
    output y6
    후 (tb_gates.v 에 붙일 모양)
        .a(a),
    .b(b),
    .y0(y0),
    .y1(y1),
    ...
    .y6(y6)
    1. input a, 의 i 앞을 클릭 → Shift+Alt 누른 채 output y6 줄의 y 바로 앞까지 드래그 → Delete. (input 과 output 은 글자 수가 같게 맞춰져 있어서 한 번에 지워진다)
    2. 커서 11개가 남은 상태에서 . 입력 → 모든 줄 앞에 .
    3. Ctrl+Shift+→ → 줄마다 이름(a, b, y0 …)이 선택됨 → Ctrl+C (커서마다 자기 줄 이름을 따로 복사)
    4. → (선택 풀고 이름 바로 뒤로) → ( 입력 → Ctrl+V → ) 입력. 줄마다 자기 이름이 들어간다
    5. Esc
    줄임형 .a, 는 .v 파일에서 오류 (2026-09-30 xvlog 로 실측): '.name implicit port connection' is not allowed in this dialect; use SystemVerilog mode instead. .a(a) 로 쓰거나, . 을 빼고 순서대로(gates DUT(a, b, y0, …)) 쓴다. 순서형은 포트 순서가 하나만 어긋나도 오류 없이 엉뚱하게 연결되므로 .a(a) 가 안전하다.
