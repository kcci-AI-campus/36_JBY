## 0. 시작 전에 — 라즈베리파이 5의 함정

라즈베리파이 5는 GPIO가 **RP1이라는 별도 칩**에 붙어 있다.
그래서 인터넷 예제 대부분이 쓰는 **`RPi.GPIO`가 동작하지 않는다.**
(`RPi.GPIO`는 `/dev/mem`으로 메인 프로세서 레지스터에 직접 접근하는데, Pi 5에는 그 주소에 GPIO가 없다.)

이 폴더의 코드는 전부 **`gpiozero`** 를 쓴다. 라즈베리파이 OS에 기본 설치돼 있고 재단 권장 라이브러리다.

```bash
# 보드에서 확인
python3 -c "import gpiozero; print(gpiozero.__version__)"

# 없으면
sudo apt install python3-gpiozero python3-lgpio
```

기존 `RPi.GPIO` 코드를 고치지 않고 쓰고 싶다면 `pip install rpi-lgpio` (API가 동일).

## 1. 배선표

**핀 번호는 BCM 번호**(gpiozero 기본)이고, 괄호는 보드의 물리적 핀 위치다.

| 부품 | 연결 | 비고 |
|---|---|---|
| **LED** | GPIO17 (11번 핀) → **330Ω 저항** → LED(+) / LED(−) → GND(9번 핀) | 저항 없으면 LED·핀 손상 |
| **버튼/스위치** | GPIO27 (13번 핀) ↔ 버튼 ↔ GND(14번 핀) | 내부 풀업 사용, 저항 불필요 |
| **부저** | GPIO18 (12번 핀) → 부저(+) / 부저(−) → GND | 능동부저 기준 |
| **PIR (HC-SR501)** | VCC→5V(2번), GND→GND(6번), **OUT→GPIO22 (15번)** | 출력이 3.3V라 그대로 연결 가능 |
| **초음파 (HC-SR04)** | VCC→5V(4번), GND→GND(20번), TRIG→GPIO23 (16번), **ECHO→분압→GPIO24 (18번)** | ⚠ 아래 참조 |
| **조도(CDS) + 커패시터** | 3.3V(1번) → CDS → **노드** → GPIO25 (22번), 노드 → 1µF 커패시터 → GND | 아날로그 근사 |

### ⚠ HC-SR04의 ECHO는 반드시 분압할 것

ECHO 핀은 **5V**로 신호를 내보낸다. GPIO는 **3.3V 전용**이라 그대로 꽂으면 핀이 망가진다.
저항 2개로 전압을 나눈다.

```
ECHO ──[ R1 = 1kΩ ]──┬── GPIO24
                     │
                  [ R2 = 2kΩ ]
                     │
                    GND
```

계산: 5V × R2/(R1+R2) = 5 × 2/3 = **3.3V**. R1=1k, R2=2k 조합이 가장 흔하다.
(1k + 2k가 없으면 10k + 20k도 동일 비율이라 괜찮다.)

### 배선 3원칙

1. **GPIO는 3.3V 전용.** 5V 신호는 분압해서 넣는다.
2. **LED에는 직렬 저항**(220~330Ω)을 반드시 넣는다.
3. **배선을 바꿀 때는 보드 전원을 끈다.** 교육장 보드는 공용 장비다.

## 3. 06번 스크립트가 만드는 결과

`06_sensor_trigger_ai.py`는 두 가지 방식을 **같은 조건에서** 돌려 CSV로 기록한다.

| 방식 | 내용 |
|---|---|
| `always` | AI를 쉬지 않고 계속 돌린다 (기존 방식) |
| `trigger` | 센서가 감지했을 때만 AI를 깨운다 (제안 방식) |

기록 항목: 평균/최대 CPU 사용률, 추론 횟수, AI 가동 시간 비율, 트리거→판정 지연(ms), 놓친 이벤트, 오경보.

이 CSV가 그대로 보고서의 **Before/After 비교표**가 된다.

```bash
python3 06_sensor_trigger_ai.py --mode always  --sec 120
python3 06_sensor_trigger_ai.py --mode trigger --sec 120
# → result_always.csv / result_trigger.csv
```

전력을 실측하려면 USB 전력계가 필요하다. 없으면 **CPU 사용률과 AI 가동 시간 비율**로 대체한다
(논리는 성립하지만, 실측이 있으면 훨씬 강하다).
